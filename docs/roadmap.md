# Roadmap

- **0.1 alpha:** CLI, SQLite inventory, SHA-256 remote readback verification, retryable uploads, basic restore.
- **0.2:** Versioned immutable object naming, retention, manifest exports, encrypted manifest replication, durable queue backoff.
- **0.3:** Discourse upload metadata adapter, filesystem event watcher plus full reconciliation, Docker deployment, metrics and alerts.
- **0.4:** PostgreSQL-consistent backup orchestration, verified encrypted database copies, coordinated point-in-time recovery.
- **1.0:** End-to-end recovery drills, disaster recovery documentation, integration tests, security audit.
